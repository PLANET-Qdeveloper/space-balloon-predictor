# Space Balloon Predictor

高高度気球の軌道を予測するGUIアプリケーション。

## インストール

Releaseから使用しているOSに合ったファイルをダウンロードしてください。

## 使い方

1. 左のパネルで各種パラメーター（放球位置・放球日・放球時刻・上昇速度・落下速度・
   バースト高度）を入力します。

   - **放球位置**：プリセットから選択するほか、緯度・経度の直接入力、あるいは
     地図上をクリックして指定できます。緯度・経度は `33.12345` のような10進数と、
     `33°07′30″` のような60進数のどちらでも入力できます。
   - **初期高度**：放球地点の海抜高度（m）を指定します。初期値は `10` m です。
   - **放球日 / 放球時刻**：気球を放つ日時を24時間形式（例: `13:00`）で指定します。
   - **上昇速度**：気球が上昇する速度（m/s）。
   - **落下速度**：バースト後、落下するときの速度（m/s）。
   - **バースト高度**：気球が破裂して落下を開始する高度（m）。

2. 必要に応じて「モンテカルロ法」を有効にすると、上昇速度・落下速度・バースト高度の
   入力欄で標準偏差（±）とサンプル数（1〜200）を指定でき、着地点の確率分布を推定できます。

3. 「予測」ボタンを押すと、放球時刻の気象データを自動で取得・解析し、
   軌道をシミュレーションします。結果は地図上に表示され、高度–時刻のチャートでも
   確認できます。

## 開発者向け

### 着地判定

降下中の現在位置の地形標高に到達した時点で終了します。放球地点の高度は終了条件に使いません。
標高10 km未満の降下は最大1秒間隔で判定し、接触区間内を二分探索して着地位置・時刻を補正します。
標高の出典は詳細設定で選べます。既定は[国土地理院のDEM10B標高タイル](https://maps.gsi.go.jp/development/ichiran.html)です。海外向けには[OpenTopoData](https://www.opentopodata.org/)（SRTM 30m）も利用でき、デフォルト URL は `https://api.opentopodata.org` です。セルフホストしたサーバーの URL にも切り替えられます。
タイルは実行中に取得し、プロセス内で共有キャッシュします。初期高度は海抜高度で入力してください。
海域・提供範囲外・欠測・通信障害で標高を取得できない区間は海抜0 mで近似し、結果画面に暫定値と表示します。
DEMの解像度と最大1秒の判定間隔より細かい地形や障害物は再現しません。

### リポジトリ構成

```
├─ src/          # React (Vite) フロントエンド
├─ src-tauri/    # Tauri バックエンド (Rust)
└─ crates/core/  # 軌道予測ライブラリ (Rust)
```

### 技術スタック

- **フロントエンド**: React 19 / TypeScript / Vite 7 / Tailwind CSS 4 / deck.gl + MapLibre GL
- **バックエンド**: Tauri 2 / Rust
- **コアライブラリ**: `crates/core`（GRIB 気象データ解析・軌道シミュレーション）

### 開発環境のセットアップ

- Rust
- Node.js

のインストールが必要です。

```bash
npm install
```

### 開発サーバーの起動

```bash
npm run tauri dev
```

### ビルド

```bash
npm run tauri build
```

### コアライブラリ

軌道予測のロジックは [crates/core](crates/core/README.md) に分離されています。
API・CLIの使い方の詳細は上記の README を参照してください。
